# 水下机器人控制系统 (Underwater Robot Control System)

本项目为微型水下机器人（ROV）竞速遥控控制系统，包含下位机嵌入式主控固件、上位机图形化遥控驾驶台及硬件电路设计文件。

---

## 一、 系统架构

```
[ PC 遥控驾驶台 ] 
      │ (USB-串口)
[ 电脑端 LoRa 模块 ]
      ≈≈≈ (433MHz 无线透传) ≈≈≈
[ 水下机器人 LoRa 模块 (PA2/PA3 - USART2) ]
      │
[ STM32F103 主控板 ]
      │ (TIM1 PWM: PA8/PA9, 方向: PB12~PB15)
[ TB6612FNG 电机驱动 ]
      │
[ 双路防水推进器 (左右差速控制) ]
```

---

## 二、 目录结构说明

* **`UWR_Class/`**：STM32F103 下位机 Keil 5 标准库工程
  * `Hardware/lora.c`, `lora.h`：LoRa 串口接收驱动（含环形接收缓冲区与数据包协议）
  * `Hardware/motor.c`, `motor.h`：TB6612 双路电机驱动（TIM1 高级定时器 PWM 调速及差速控制）
  * `User/main.c`：主控联动控制逻辑与 350ms 防失控安全看门狗
* **`lora_controller.py`**：基于 PyQt5 的桌面端 LoRa 遥控上位机
* **`run_controller.bat`**：上位机一键启动脚本
* **`水下课设原理图&BOM.pdf`**：硬件原理图与元器件选型采购清单
* **`水下课设/`**：立创 EDA 硬件电路及 PCB 工程源文件

## 三、 遥控操作指南

| 按键 | 功能操作 | 说明 |
| :--- | :--- | :--- |
| **`W`** | 前进 | 左右推进器同速正转 |
| **`S`** | 后退 | 左右推进器同速反转 |
| **`A`** | 左转 | 左右推进器差速/原地左转 |
| **`D`** | 右转 | 左右推进器差速/原地右转 |
| **松开按键** | **自动停机** | 停止发送指令，推进器平稳断电 |
| **`E` / `↑` / `+`** | 加速 | 航行初始/设定速度递增 50 |
| **`Q` / `↓` / `-`** | 减速 | 航行初始/设定速度递减 50 |
| **`Space` (空格)** | 紧急制动 | 双路推进器短路强刹车 |

> **安全保护**：当下位机连续超过 350ms 未接收到上位机有效运动心跳时，自动切断 PWM 输出，防止失控冲撞。
